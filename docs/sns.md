# SNS

## 固定タグ
- #TomarigiDesktop — 製品名。毎回付ける。#tomarigi だけだと同名のイベントやカフェの投稿と混ざる（ユーザー発言）。ハイフンは X のタグで切れるので使えない。アンダースコアではなく単語の頭を大文字にする形（ユーザーの判断「おkそれで」。打ち間違えても同じタグにまとまる・読み上げで単語が分かれる、は Claude が挙げた理由）

## 話題タグ
- #ClaudeCode — Claude Code のセッションの見え方・連携に関わる更新のとき
- #Codex — Codex 対応に関わる更新のとき

## 文面
- 更新の告知でも、毎回まず「どういうアプリか」を書いてから更新内容を書く。知名度が無く、初めて見る人が多いため（ユーザー発言「ちめいどがないから、まずどういうあぷりかのせつめいもほしいんだよ。じかいから。るーるにかいておいて」）。説明の元は README 冒頭の一文（AI コーディングエージェント（Claude Code / Codex）のセッションを、常に手前に出る窓の中の鳥として見守る macOS アプリ。鳥を押すとそのセッションの Ghostty のペインへ飛ぶ）
- 説明を入れると 280 に収まらないときは、更新内容をいちばん大きい 1 件に絞る（Claude の自己判断）
