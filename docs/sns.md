# SNS

## 固定タグ
- #TomarigiDesktop — 製品名。毎回付ける。#tomarigi だけだと同名のイベントやカフェの投稿と混ざる（ユーザー発言）。ハイフンは X のタグで切れるので使えない。アンダースコアではなく単語の頭を大文字にする形（ユーザーの判断「おkそれで」。打ち間違えても同じタグにまとまる・読み上げで単語が分かれる、は Claude が挙げた理由）

## 話題タグ
- #ClaudeCode — Claude Code のセッションの見え方・連携に関わる更新のとき
- #Codex — Codex 対応に関わる更新のときと、Codex を含むどのエージェントのセッションにも効く更新（見え方・連携）のとき。#ClaudeCode と同じ条件で付け、片方だけにしない（ユーザー発言「codexもつけるようにして。けんさくりゅうにゅうみこみ」）

## 文面
- 更新の告知でも、毎回まず「どういうアプリか」を書いてから更新内容を書く。知名度が無く、初めて見る人が多いため（ユーザー発言「ちめいどがないから、まずどういうあぷりかのせつめいもほしいんだよ。じかいから。るーるにかいておいて」）。説明の元は README.ja.md 冒頭の一文で、毎回 README から取り直す（対応するエージェントと OS が増えていくため。エージェントは全部並べず数個と「など」にする。説明は「どういうアプリか」の 1 文だけにし、鳥を押すとペインへ飛ぶなどの機能は毎回は書かない（ユーザー発言「これもいちいちまいかいかかんでいいねん」）。全部並べたら「ながいねんか」と言われた。Claude Code / Codex だけと書いたら、ユーザーに「claude code,codexだけじゃないねんか」と指摘された）
- 投稿するアカウントは X Premium なので、280 字の制限は無い（ユーザー発言「premiumやからもじすうせいげんはないで」）。それでも更新を全部は書かず、版ごとにも分けない。冒頭に最新の版番号を書き、使う人に見える大きい変化だけを数個の箇条書きにする（ユーザー発言「ばーじょんばんごうもいれてな」「いや、ぜんぶかかないで。ばーじょんごとにかくのはやめて」）
- 文の先頭には Claude Code・Codex などのエージェント名を置き、Tomarigi を前面に出さない。読む人が知っているのはエージェントのほうなので、そこから入る（ユーザー発言「ついーとぶんは、tomarigiをぜんめんにだすんじゃなく、claudecodeとかをぶんしょうのせんとうにおくようにしろよ」。理由の文は Claude の推測）
